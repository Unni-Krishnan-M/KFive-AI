# Remote Mode

Remote mode is planned and unverified. Set `KFIVE_MODE=remote`, configure externally reachable service URLs, strong secrets, an exact public origin, HTTPS ingress, and a remote AI provider. Ollama, OpenAI Chat Completions, Anthropic Messages, OpenAI-compatible, and custom-compatible adapters exist, but remote TLS/Traefik deployment and external-provider smoke paths have not been executed.
